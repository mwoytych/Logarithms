Logarithm Basics

log_b(x) = y
     ⇔
b^y = x

Logs answer:
"What exponent?"

Common & Natural Logs

log(x) = log₁₀(x)
ln(x)  = logₑ(x)

e ≈ 2.718

Exact Values

log(1)   = 0
log(10)  = 1
log(100) = 2

ln(1)  = 0
ln(e)  = 1
ln(e³) = 3

Log Properties

Product:
log(MN) = log(M) + log(N)

Quotient:
log(M/N) = log(M) − log(N)

Power:
log(Mᵖ) = p · log(M)

Expand Mechanics

Multiply   → Add
Divide     → Subtract
Power      → Front

Condense Mechanics

Add          → Multiply
Subtract     → Divide
Coefficient  → Exponent

Change of Base

log_b(x) = log(x) / log(b)

Also valid with ln:
log_b(x) = ln(x) / ln(b)

Domain & Range

Domain:
Set the inside > 0
and solve for x.

Range:
All real numbers
(−∞, ∞)

Graph Facts

Vertical Asymptote: x = 0
Key Point:          (1, 0)

Concave Down for
log(x) and ln(x)

Asymptotes

Graph approaches x = a

Graph approaches y = b

Limits

lim ln(x) = −∞
x→0⁺

Growth Models

P = P₀(1 + r)^t

Growth: r positive
Decay:  r negative

Continuous Growth

A = A₀e^(kt)

k > 0  →  Growth
k < 0  →  Decay
Question #3 "How do I know when to use logarithms?"

Convert Forms

ab^t → ae^(kt)
k = ln(b)

ae^(kt) → ab^t
b = e^k

Finding Time

ab^t = c
t = log(c/a) / log(b)

ae^(kt) = c
t = ln(c/a) / k

Half-Life

t = ln(2) / |k|

Meaning:
Time to cut
in half.

Doubling Time

t = ln(2) / k

Meaning:
Time to double.

Applications

pH = −log[H+]

Decibels = 10 log(I / I₀)

Solve Exponential Equations

Variable in exponent?
Take logs.

Example:
2^x = 50

x = log(50) / log(2)

When Logs Fail

2^x + x = 10

Variable inside
exponent AND
outside exponent

Cannot solve
algebraically
with logs.
