Chapter 5 Formula Reference

Complete Formula Sheet for Logarithms & Exponential Models

Logarithm Definition

logb(x) = y ⇔ by = x

A logarithm answers: "What exponent?"

Common & Natural Logs

Common: log(x) = log10(x) ------------------------- Natural: ln(x) = loge(x) e ≈ 2.718

Exact Values

log(1) = 0 log(10) = 1 log(100) = 2 log(1000) = 3 ------------------------- ln(1) = 0 ln(e) = 1 ln(e²) = 2 ln(e³) = 3

Inverse Relationships

log(10x) = x ------------------------- 10log(x) = x ------------------------- ln(ex) = x ------------------------- eln(x) = x

Product Rule

log(MN) = log(M) + log(N)

Quotient Rule

log(M/N) = log(M) − log(N)

Power Rule

log(Mp) = p · log(M)

Change of Base

logb(x) = log(x) / log(b) = ln(x) / ln(b)

Expansion Mechanics

Multiply → Add Divide → Subtract Power → Front

Condensing Mechanics

Add → Multiply Subtract → Divide Coefficient → Exponent

Domain of Logs

Inside > 0 Always.

Example:

log(x − 5) x − 5 > 0 x > 5

Range of Logs

(−∞, ∞) All Real Numbers

Asymptotes

Vertical: x = a ------------------------- Horizontal: y = b

Parent Log Graph

Domain: (0, ∞) Range: (−∞, ∞) Vertical Asymptote: x = 0 Key Point: (1, 0)

Concavity

log(x) → Concave Down ln(x) → Concave Down

Limits

lim ln(x) = −∞ x→0⁺ ------------------------- lim ln(x) = ∞ x→∞

Growth Model

P = P₀(1 + r)t

r > 0

Decay Model

P = P₀(1 − r)t

r > 0

Continuous Growth/Decay

A = A₀ekt k > 0 → Growth k < 0 → Decay

Convert Forms

abt → aekt k = ln(b) ------------------------- aekt → abt b = ek

Find Time

abt = c t = log(c/a) / log(b) ------------------------- aekt = c t = ln(c/a) / k

Annual Growth Rate

b = 1 + r ------------------------- r = b − 1

Half-Life

t½ = ln(2) / |k|

Time required to reach half.

Doubling Time

td = ln(2) / k

Time required to double.

pH Formula

pH = −log[H⁺]

Sound Intensity

dB = 10 · log(I / I₀)

Solving Exponential Equations

Variable in exponent? ↓ Take logarithms.

Example:

3x = 40 x = log(40) / log(3)

When Logs Will NOT Work

2x + x = 10

Variable appears:

Inside exponent AND Outside exponent

Requires:

Graphing Numerical Methods Technology
