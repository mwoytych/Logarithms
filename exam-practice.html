1. Evaluating Logarithms

Rewrite logb x = y as by = x. Evaluate without a calculator.

  1. log₂ 32
    Show answer

    5 — because 2⁵ = 32.

  2. log₃ (1/9)
    Show answer

    −2 — because 3⁻² = 1/9.

  3. log 0.001
    Show answer

    −3 — common log has base 10, and 10⁻³ = 0.001.

  4. ln e⁴
    Show answer

    4 — ln and eˣ are inverses.

  5. log₄ 8
    Show answer

    4ˣ = 8 → 2²ˣ = 2³ → 2x = 3, so x = 3/2.

2. Domain, Range & Asymptotes

The argument of a log must be greater than 0. Set it > 0 to find the domain; the vertical asymptote is where the argument equals 0.

  1. Find the domain and vertical asymptote of f(x) = log(x − 3).
    Show answer

    x − 3 > 0 → domain: (3, ∞); vertical asymptote: x = 3.

  2. Find the domain of f(x) = ln(5 − 2x).
    Show answer

    5 − 2x > 0 → x < 5/2. Domain: (−∞, 5/2). Note the inequality flips when dividing by −2.

  3. Find the domain of f(x) = log₂(x² − 4).
    Show answer

    x² > 4 → x < −2 or x > 2, i.e. (−∞, −2) ∪ (2, ∞).

  4. State the range and vertical asymptote of g(x) = ln(x + 1) + 2.
    Show answer

    Range: all real numbers. Vertical asymptote: x = −1. The +2 shifts the graph up but does not move the asymptote.

3. Log Properties & Change of Base

  1. Expand log₃(9x² / y).
    Show answer

    log₃ 9 + 2 log₃ x − log₃ y = 2 + 2 log₃ x − log₃ y.

  2. Condense 2 ln x + ln 3 − ln y into a single logarithm.
    Show answer

    ln x² + ln 3 − ln y = ln(3x² / y).

  3. Use change of base to approximate log₅ 20.
    Show answer

    ln 20 / ln 5 ≈ 2.9957 / 1.6094 ≈ 1.861.

4. Solving Exponential & Logarithmic Equations

Same base? Match exponents. Different bases? Take a log of both sides. Always verify log solutions against the domain.

  1. Solve 3ˣ = 81.
    Show answer

    81 = 3⁴, so x = 4.

  2. Solve 52x−1 = 40. Give a decimal answer.
    Show answer

    (2x − 1) ln 5 = ln 40 → 2x − 1 ≈ 2.292 → 2x ≈ 3.292 → x ≈ 1.646.

  3. Solve 2e0.3x = 14.
    Show answer

    e0.3x = 7 → 0.3x = ln 7 → x = ln 7 / 0.3 ≈ 6.486.

  4. Solve log₂(x + 3) = 5.
    Show answer

    x + 3 = 2⁵ = 32 → x = 29. Check: 29 + 3 > 0 ✓.

  5. Solve ln x + ln(x − 2) = ln 8.
    Show answer

    x(x − 2) = 8 → x² − 2x − 8 = 0 → x = 4 or x = −2. Since x must be greater than 2, reject −2. x = 4.

  6. Solve 3ˣ = −5.
    Show answer

    No solution. 3ˣ is always positive, and the log of a negative number is undefined.

  7. Can 2ˣ = 5x be solved exactly using logarithms? Why or why not?
    Show answer

    No. The variable appears both as an exponent and as a base term, so logs cannot isolate it. Use a graph or numerical method (find where the two graphs intersect).

5. Growth, Decay, Half-Life & Doubling Time

Annual: A = P(1 + r)t  |  Continuous: A = Pert  |  Half-life: A = A₀(1/2)t/h  |  Doubling time: t = ln 2 / ln(1 + r)

  1. $2,000 grows at 5% compounded annually. Find the value after 8 years.
    Show answer

    2000(1.05)⁸ ≈ $2,954.91.

  2. The same $2,000 grows at 5% compounded continuously for 8 years. Find the value.
    Show answer

    2000e0.05·8 = 2000e0.4 ≈ $2,983.65.

  3. 80 mg of a substance has a half-life of 6 days. How much remains after 15 days?
    Show answer

    80(1/2)15/6 = 80(0.5)2.5 ≈ 14.14 mg.

  4. A population grows 4% per year. How long until it doubles?
    Show answer

    1.04ᵗ = 2 → t = ln 2 / ln 1.04 ≈ 17.67 years.

  5. Rewrite y = 500(1.08)ᵗ in the form y = aekt.
    Show answer

    k = ln 1.08 ≈ 0.0770, so y ≈ 500e0.0770t.

  6. A substance decays continuously at 3% per year. How long until 25% remains?
    Show answer

    e−0.03t = 0.25 → t = ln 4 / 0.03 ≈ 46.21 years.

6. pH & Decibel Applications

pH = −log[H⁺]  |  Loudness: L = 10 log(I / I₀), where I₀ = 10⁻¹² W/m²

  1. Find the pH of a solution with [H⁺] = 3.2 × 10⁻⁵.
    Show answer

    pH = −log(3.2 × 10⁻⁵) = 5 − log 3.2 ≈ 4.49.

  2. A sound has intensity I = 10⁻⁵ W/m². Find its loudness in decibels.
    Show answer

    L = 10 log(10⁻⁵ / 10⁻¹²) = 10 log(10⁷) = 70 dB.
