Core Definition

A logarithm answers: "To what power must I raise the base to get this number?"

log_b(x) = y  ⟺  b^y = x
⚠️ Non-Negotiable Constraints
  • Base (b): Must be > 0 and ≠ 1
  • Argument (x): Must be > 0
  • Result (y): Can be any real number

Fundamental Properties

Logarithm Properties
Property Formula Condition
Product log_b(MN) = log_b M + log_b N M, N > 0
Quotient log_b(M/N) = log_b M - log_b N M, N > 0
Power log_b(M^p) = p · log_b M M > 0

Essential Derived Forms

Reciprocal argument:  log_b(1/M)    = -log_b M
Root rule:             log_b(n√M)    = (1/n)·log_b M
Base as power:         log_(b^n)(M)  = (1/n)·log_b M
Chain identity:        log_a(b)·log_b(c) = log_a(c)
Reciprocal base:       log_(1/b)(x)  = -log_b(x)

Trap Alert: Common False Properties

❌ These are FALSE:
  • log(M + N) ≠ log M + log N
  • log(M · N) ≠ log M · log N
  • log(M / N) ≠ log M / log N
  • (log M)² ≠ log(M²)

Change of Base

Essential for calculators and comparing different bases.

log_b(x) = log_k(x) / log_k(b)    for any valid k > 0, k ≠ 1

Standard Notation:

  • log x = log₁₀ x (Common Logarithm)
  • ln x = log_e x (Natural Logarithm, e ≈ 2.718)

The Logarithm Function

Domain: (0, ∞)  |  Range: (-∞, ∞)

Log Function Behavior by Base
Feature Base b > 1 Base 0 < b < 1
Behavior Increasing Decreasing
As x → 0⁺ y → -∞ y → +∞
As x → ∞ y → +∞ y → -∞
Concavity Concave Down Concave Up

Solving Equations

Logarithmic Equations

  1. Same Base: Drop the logs. If log_b M = log_b N, then M = N.
  2. Mixed Bases: Use Change of Base to unify them.
  3. Substitution: If you see 4^x and 2^x, let u = 2^x.
⚠️ The Golden Rule of Log Equations

Always check your domain before solving. Any solution that makes an argument ≤ 0 is extraneous and must be rejected.

Exponential Equations

  1. Same Base: Equate the exponents.
  2. Different Bases: Take the natural log (ln) of both sides.
  3. Quadratic Form: Substitute u = b^x and solve the quadratic.

Inequalities

⚠️ Direction Rule
  • Base > 1: Inequality direction preserved.
  • 0 < Base < 1: Inequality direction flips.

Two Conditions Required:

  1. Argument > 0 (Domain)
  2. Solve the inequality
  3. Intersect the results

Exponential Models

Applications

  • pH: pH = -log₁₀[H⁺]
  • Decibels: β = 10·log₁₀(I/I₀)
  • Richter: M = log₁₀(A/A₀)
  • Rule of 72: Doubling time ≈ 72 / percent rate

Exam Tips & Tricks

  1. Telescoping: log₂3 · log₃4 · log₄5 = log₂5
  2. ln Approximations: ln 2 ≈ 0.693, ln 3 ≈ 1.099, ln 10 ≈ 2.303
  3. Exponential of Log: b^(log_b x) = x (simplifies instantly)
  4. Substitution: Look for a^(2x) patterns to use u = a^x
  5. Check Domain First: Saves time on extraneous solutions
