Mechanic #1: Translate Logarithms

Translation Rule

logb(x)=y

⇔

b^y=x
Example: 
log₂(32)

Question:

2^? = 32

Answer:

5

Mechanic #2: Expand Logarithms

Operation Log Rule
Multiply Add
Divide Subtract
Power Bring Exponent Forward
Example: 
log((x²y)/z³)

↓

log(x²)+log(y)-log(z³)

↓

2log(x)+log(y)-3log(z)

Mechanic #3: Condense Logarithms

Expression Action
+ Multiply
- Divide
Coefficient Exponent
Example: 
2log(x)+log(y)-3log(z)

↓

log(x²)

+

log(y)

-

log(z³)

↓

log((x²y)/z³)

Mechanic #4: Find Domains

Golden Rule

Inside > 0
Example:

x-4 > 0

x > 4

Domain:

(4,∞)

Mechanic #6: Solve Exponential Equations

Example: 
2^x = 20

Take logs.

log(2^x)=log(20)

x log(2)=log(20)

x=log(20)/log(2)

Trigger

If the variable is trapped in an exponent, use logarithms.

Mechanic #7: Find Time in Growth & Decay Models

Annual growth model: 
ab^t = c

t =
log(c/a)
/ log(b)
Continuous model: 
ae^(kt) = c

t =
ln(c/a)
/ k

Mechanic #8: Half-Life & Doubling Time

Half-Life

t = ln(2)/|k|

Time needed for quantity to be cut in half.

Doubling Time

t = ln(2)/k

Time needed for quantity to double.

Mechanic #9: Know When Logs Fail

Example:

Outside exponent

with logarithms alone.
