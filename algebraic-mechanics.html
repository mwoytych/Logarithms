Mechanic #1: Translate Logarithms

Translation Rule

log_b(x) = y   ⇔   b^y = x

A logarithm answers the question: "What exponent produces this value?" 

log₂(32)

Question: 2^? = 32
Answer:   5

Mechanic #4: Find Domains

Golden Rule

Inside > 0

The argument of a logarithm must always be positive.

y = log(x − 4)

x − 4 > 0
x > 4

Domain: (4, ∞)

Mechanic #5: Analyze Graphs

Parent Function: y = log_b(x)

Domain:     x > 0
----------------------
Range:      All Real Numbers (−∞, ∞)
----------------------
Asymptote:  x = 0  (vertical)
Key Point:  (1, 0)

The graph crosses the x-axis at x = 1 and approaches the vertical asymptote without ever touching it.

Transformations

y = a · log_b(k(x − d)) + c

a → vertical stretch / reflection
k → horizontal stretch / compression
d → horizontal shift (moves the asymptote too)
c → vertical shift

Mechanic #6: Solve Exponential Equations

Two Paths

Common base possible?  →  Match exponents
Otherwise             →  Take log of both sides
2^(x+1) = 32
2^(x+1) = 2^5
x + 1 = 5
x = 4
3^x = 20
log(3^x) = log(20)
x · log(3) = log(20)
x = log(20) / log(3) ≈ 2.727

Mechanic #7: Growth & Decay Models

Standard Forms

Growth:      A = P · b^t      (b > 1)
Decay:       A = P · b^t      (0 < b < 1)
Continuous:  A = P · e^(rt)

P = initial amount, A = amount at time t, b = growth or decay factor, r = continuous rate. 

Half-life:   A = P · (1/2)^(t/h)
Doubling:    A = P · 2^(t/d)

h = half-life      d = doubling time

Mechanic #8: Verify Your Answer

  • Substitute back into the original equation.
  • Check that every logarithm argument is still positive.
  • Reject extraneous solutions introduced by exponentiating.
  • Confirm units and reasonableness (time > 0, mass ≥ 0).
