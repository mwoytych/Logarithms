Common Mistakes

Avoid these errors and immediately improve exam performance.

Mistake #1: Splitting Addition

❌ Wrong
log(a + b) = log(a) + log(b)
✅ Correct
There is NO rule for log(a + b)

Mistake #2: Incorrect Domain Rule

❌ Wrong
Inside ≥ 0
✅ Correct
Inside > 0

Logarithms cannot accept zero — the argument must be strictly greater than zero.

Mistake #3: Forgetting Domain Checks

After solving a logarithmic equation:

Always verify: Argument > 0

Otherwise an extraneous solution may appear.

Mistake #4: Mixing Product and Quotient Rules

Product → Add Quotient → Subtract

Mistake #5: Forgetting the Power Rule

❌ Wrong
log(x²) = (log(x))²
✅ Correct
log(x²) = 2 log(x)

Mistake #6: Confusing Domain and Range

Domain: x > 0 Range: All Real Numbers

Mistake #7: Missing the Vertical Asymptote

y = log(x) Vertical Asymptote: x = 0

The graph approaches but never reaches the asymptote.

Mistake #8: Wrong Growth Formula

✅ Growth
P = P₀(1 + r)^t
✅ Decay
P = P₀(1 - r)^t

Mistake #9: Confusing Annual and Continuous Growth

Annual: ab^t Continuous: ae^(kt)

Mistake #10: Incorrect Conversion

To convert:

ab^t → ae^(kt) k = ln(b)

To convert back:

b = e^k

Mistake #11: Wrong Half-Life Formula

Half-Life = ln(2) / |k|

Use absolute value because decay constants are negative.

Mistake #12: Wrong Doubling Time Formula

Doubling Time = ln(2) / k

Mistake #13: Solving the Wrong Equation

2^x = 50

Variable is trapped in an exponent — take logarithms.

Mistake #14: Not Recognizing When Logs Can't Help

2^x + x = 10

Variable appears:

  • Inside exponent
  • Outside exponent

Logs cannot isolate x exactly — use graphing or numerical methods.

Mistake #15: Memorizing Without Understanding

Students often memorize:

Product Rule Quotient Rule Power Rule

but forget:

Why they work.

Understanding the mechanics improves retention.
