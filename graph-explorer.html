Logarithm Parent Function

The most important logarithm graph is: 

y = log(x)

or

y = ln(x)
  • Domain: x > 0
  • Range: All Real Numbers
  • Vertical Asymptote: x = 0
  • Key Point: (1,0)
  • Concavity: Down

Domain & Range Explorer

Domain Rule

Inside > 0
Example: 
y = log(x-4)

x-4 > 0

x > 4

Range Rule

(-∞ , ∞)
The range of a logarithm function is all real numbers.

Vertical Asymptotes

x = 0

Meaning:

  • The graph approaches the line.
  • The graph never touches the line.
  • The function is undefined there.
Exam Question Example 
y = log(x-5)

Set Inside = 0

x-5 = 0

Asymptote:

x = 5

Horizontal Asymptotes

Usually appear on exponential functions. 

y = (1/2)^x
Horizontal asymptote: 
y = 0
Meaning:
  • Graph approaches y=0
  • Graph never reaches y=0

Concavity

y = log(x)

y = ln(x)
Concavity: 
Concave Down

The function is increasing but rises slower and slower.

Interpretation

As x gets extremely close to zero from the positive side, the logarithm decreases without bound. As x becomes very large, the logarithm grows forever, but slowly.

Growth vs Decay

Growth

y = 2^x
  • Increasing
  • Rises quickly
  • Horizontal asymptote y=0

Decay

y = (1/2)^x
  • Decreasing
  • Approaches zero
  • Horizontal asymptote y=0

Inverse Relationship

y = 2^x

and

y = log₂(x)
  • Inverse functions
  • Reflections across y=x
  • Undo each other
log₂(2^x)=x

2^(log₂(x))=x
